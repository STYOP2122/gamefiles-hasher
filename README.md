# Game Files Hasher

Windows-утилита для создания манифеста игровых файлов. Программа обходит выбранную папку, вычисляет SHA256 каждого файла и сохраняет относительный путь, размер и хеш в JSON. Такой манифест можно использовать при проверке файлов в лаунчере.

## Версии в репозитории

- `HasherWin/` — графическое приложение на C# и Windows Forms, .NET 8.
- `Hasher/` — отдельная реализация на C++.
- `Hasher.sln` — решение Visual Studio.

## Запуск графического приложения

Понадобятся Windows и .NET 8 SDK.

```bash
git clone https://github.com/STYOP2122/gamefiles-hasher.git
cd gamefiles-hasher
dotnet run --project HasherWin/HasherWin.csproj
```

Выберите папку с файлами и путь сохранения JSON. Приложение показывает прогресс обработки; имя выходного файла по умолчанию — `client.json`.

## Формат манифеста

```json
{
  "files": [
    {
      "name": "models/example.dat",
      "size": 1024,
      "hash": "<SHA256 файла>"
    }
  ]
}
```

Пути записываются относительно выбранной папки. Хеш представлен строчными шестнадцатеричными символами.

Для сборки C++-проекта откройте решение в Visual Studio с установленным набором инструментов v145 или перенастройте набор инструментов под свою среду.
